# ABL Customer Statement Intelligence Suite

AI-powered customer statement intelligence system developed as part of the Allied Bank Internship Program.

## Modules

- Account Statement Q&A
- Subscription / Recurring Payment Analysis
- ABL Policy Q&A using RAG

## Technology Stack

- React.js
- Tailwind CSS
- FastAPI
- PostgreSQL
- pgvector
- Google Gemini
- Sentence Transformers
